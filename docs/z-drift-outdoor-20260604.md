## Why BA Can Make This Worse

BA optimizes local consistency, not absolute true height:

```text
min E(x) = E_lidar(x) + imu_coef * E_imu(x)
```

When the Hessian has a weak Z direction, the optimizer can move the sliding-window states along Z while changing LiDAR residuals only slightly. If this also reduces the IMU residual, the local optimizer can accept a Z-shifted solution even though global height becomes worse.

The feedback path is:

```text
LIO estimates current frame
BA optimizes x_buf
optimized last x_buf state is written back to x_curr
optimized window is used for local map marginalization/update
next LIO frame matches against the BA-shifted local map
```

Therefore, a bad BA update is not just an output artifact. It can contaminate the next front-end matching problem through `x_curr` and the local map.

Example from frame `6798`:

```text
z_lio:       -18.333
z_ba:        -18.824
delta_z_ba:   -0.490

imu_res_before:    0.896
imu_res_after:     0.006
lidar_res_before:  0.071
lidar_res_after:   0.072
```

The optimizer reduced IMU residual strongly while barely changing LiDAR residual. Locally this can look acceptable, but the accepted update pushed Z in the wrong direction.

This allows direct comparison between the old Lidar+IMU BA and the new Lidar+Normal+IMU BA call.

## Current Recommendations

Short-term guardrails:

```text
1. If lio_success == false, do not push the modified x_curr into x_buf or the local map.
2. Add a BA accept/reject gate before writing optimized x_buf back to x_curr.
3. Reject or damp BA Z updates when nnt_eig0 is low and the weakest direction is close to Z.
4. Compare BA with and without normalFactor on the same full dataset.
5. Sweep LocalBA.imu_coef to test whether stronger IMU weighting reduces Z drift.
```

Suggested experiments:

```text
General.if_BA: 0
General.if_BA: 1 with old Lidar+IMU BA
General.if_BA: 1 with Lidar+Normal+IMU BA
General.if_BA: 1 with a higher LocalBA.imu_coef
General.if_BA: 1 but no BA writeback/map update when front-end degeneracy is detected
```
